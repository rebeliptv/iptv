## What's New

- **College football is here, with the rankings.** Games from the college slate now appear alongside the professional leagues, and a ranked side is labelled the way you would hear it called — "#6 Indiana Hoosiers vs #1 Ohio State Buckeyes" — in the guide, in the playlist and on the dashboard. On a busy Saturday that is the difference between spotting the game of the week and scrolling past it.
- **Less chance of losing live sports listings for no visible reason.** The service we read game schedules from turns away requests that look like they came from an out-of-date browser, and what it accepts has been tightening. Some setups had already started coming up with an empty sports section and nothing anywhere to say why. We now identify ourselves as a current browser again, which puts a comfortable margin back.
- **A cut-short guide download no longer costs you the TV guide.** The guide arrives as one large file, and if the connection dropped part-way through it was written off until the next refresh — which is what left some guides blank for hours at a time. An interrupted download is now retried before it is given up on.
- **A game could occasionally be showing the wrong sport's stream.** Teams are matched to a game by name, and a college side whose city it shares with a professional club — Miami, Washington, Houston and around half the others — could quietly resolve to that club instead. When both sides of a fixture did it, the stream was filed against that club's game, so a baseball fixture could open on a college football feed. It happened at random and never twice the same way, which is why it was hard to pin down.
- **Placeholder fixtures no longer clutter the guide.** A bowl or playoff slot published before the teams are known was appearing as a "TBD" entry, and several on the same day would land on top of one another. They are left out until there is an actual matchup to show.

## Update

Already running Rebel IPTV? Update to this version — your data (the `iptv-data` volume) is kept. From the dashboard, click **Update now** on the Dashboard or in **Settings → Server** (on the `:latest` image with the Docker socket mounted). Or from the command line:

```bash
docker pull rebeliptv/iptv:1.4.3
docker compose up -d
```

Setting up a **new** instance? The step-by-step guide at **https://www.rebeliptv.com** builds a Docker configuration for your system — ports, timezone, in-app updates, and more — so you copy a setup that fits your box instead of a generic one.

Image: `rebeliptv/iptv:1.4.3` (also published as `rebeliptv/iptv:latest`).

## Endpoints

| URL | Description |
|-----|-------------|
| `http://<server>:8080/playlist?key=YOUR_KEY` | M3U playlist |
| `http://<server>:8080/epg?key=YOUR_KEY` | EPG guide (XML) |
| `http://<server>:8080/epg.gz?key=YOUR_KEY` | EPG guide (gzip) |
| `http://<server>:8080` | Web dashboard |

> **Note:** The `?key=` parameter is only required if an API key has been generated in the web dashboard under **Settings**.
