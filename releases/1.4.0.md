## What's New

- **Streams nobody is watching now close on their own.** A stream could keep running after everyone stopped watching it, tying up one of your connections until you restarted the container.
- **Fewer failures when several channels play at once.** Every channel playing needs its own connection out to the source, and nothing was counting them — so opening a few at once could exceed what the line behind them allows, and the extra ones came back as an error instead of a picture. Your server now tracks what each source has open and picks one with room.
- **"Tuners" is now "Simultaneous streams", and it is a real limit.** It used to be a number only some players were told about, and nothing enforced it. It now applies however you connect, including this dashboard, and it has moved out from behind the HDHomeRun switch so playlist users can set it too. Watching the same channel on several devices still counts as one. **If you never set it, it is now 4** — raise it in Settings → Connect if you regularly watch more at once. A channel over the limit shows a "stream limit reached" card and starts on its own as soon as another stops.
- **The hourly feed check no longer interrupts what you are watching.** It could open a burst of connections to the same place you were streaming from and knock you off your channel. It now waits for live playback.
- **Channels that froze after about twenty minutes keep playing now.** Some channels use an access link that quietly expires; your server renews it in the background, mid-stream, without interrupting the picture.
- **Channels that lost their sound recover by themselves.** A few feeds change their audio format when they reconnect, which left you with a picture and silence until you reloaded.
- **A single bad channel can no longer take the whole server down.** One unusual video format crashed everything, ending every other stream with it.
- **A channel that stuttered once is no longer sidelined for hours.** On a channel with one source, a brief freeze that recovered on its own still counted against it, so you would meet a "reconnecting" card long after it was playing perfectly.
- **The copy buttons work on phones and tablets.** Copying a playlist or guide URL could quietly do nothing while still showing a tick, so you would paste something older — often a URL without your key. If a browser refuses to let the page copy at all, the URL now appears ready to copy by hand.
- **Guide addresses work when you have set an API key.** `/xmltv.xml`, `/guide`, `/xml` and the rest dropped the key when forwarding you on, so the guide answered "api key required" and never loaded.
- **The guide no longer loses its last hour on the clock-change weekends.** Those two days are 23 and 25 hours long, and the guide was measuring in flat 24-hour blocks.
- **Live scores no longer jump backwards during a game.**
- **More sports are filed correctly in the guide**, so the per-sport folders in Jellyfin, Plex and Emby pick them up.
- **Soccer head-to-head records show draws again** — a 2-2-1 record read as "2 W / 1 L".

## Update

Already running Rebel IPTV? Update to this version — your data (the `iptv-data` volume) is kept. From the dashboard, click **Update now** on the Dashboard or in **Settings → Server** (on the `:latest` image with the Docker socket mounted). Or from the command line:

```bash
docker pull rebeliptv/iptv:1.4.0
docker compose up -d
```

Setting up a **new** instance? The step-by-step guide at **https://www.rebeliptv.com** builds a Docker configuration for your system — ports, timezone, in-app updates, and more — so you copy a setup that fits your box instead of a generic one.

Image: `rebeliptv/iptv:1.4.0` (also published as `rebeliptv/iptv:latest`).

## Endpoints

| URL | Description |
|-----|-------------|
| `http://<server>:8080/playlist?key=YOUR_KEY` | M3U playlist |
| `http://<server>:8080/epg?key=YOUR_KEY` | EPG guide (XML) |
| `http://<server>:8080/epg.gz?key=YOUR_KEY` | EPG guide (gzip) |
| `http://<server>:8080` | Web dashboard |

> **Note:** The `?key=` parameter is only required if an API key has been generated in the web dashboard under **Settings**.
