## What's New

- **We're now accepting sponsors.** Rebel IPTV is 100% community funded. Sponsoring is entirely optional — nothing is locked behind it, and nothing changes for you if you never do — but if you'd like to support the project there's now a link at the foot of your Dashboard, and anyone who does is listed there as a thank-you.
- **Fight cards and races are on the Sports page.** It now has two tabs, **Team sports** and **Event sports**. Each card or race gets its own page with the full line-up — every bout, main event first, winners marked once decided, or the full field for a race. They play like any other event and appear in your playlist, tuner and guide alongside the games, each league in its own colour.
- **Restart the server from the dashboard.** **Settings → Server → Restart Server** restarts on the same version and keeps everything: channels, guide data, metrics and settings. Anyone watching is dropped for a second or two, and the dashboard reconnects on its own. It works on any setup, including version-pinned servers and ones without the Docker socket mounted.
- **Live streams hold their buffer now.** "Buffer live feeds" used to run out a few seconds after you started a channel, and from then on every hiccup reached your player directly — which is why turning it up helped at first and then stopped, and why closing and reopening a channel fixed it for a while. The buffer now stays full for the whole stream, covers a hiccup instead of passing it on, and refills itself afterwards. Live sport gains the most. Nothing to change, and channels still start just as quickly.
- **The Sports page no longer depends on your network reaching the outside world.** Schedules, live scores and team details now arrive ready to use, so the page can't be emptied or frozen by something your server can't reach. If listings can't be refreshed, the page tells you they may be out of date.
- **Fewer channels wrongly showing offline.** Channels that had dropped out of the lineup are back, a channel stays put when a provider is slow to answer instead of disappearing until the next refresh, and each channel's real status now shows as soon as a refresh finishes.
- **Refreshes are faster and fail far less often.** Your server now picks its own start time within 20 minutes of the schedule and keeps it, waits for providers that are slow to send a large channel list instead of giving up on them, and downloads those lists compressed — some more than ten times smaller. Guide and channel-list updates go through much more reliably as a result. Your refresh may now begin up to 20 minutes after the scheduled time; nothing else about it changes.
- **Custom sources can't point back at your own server.** Adding your server's own playlist, guide or streams as a custom source is now refused with an explanation, instead of leaving the server fetching from itself in a loop.
- **A data folder your server can't write to now says so at startup.** Usually it's owned by a different user on the host. Your server names the folder and tells you to check its ownership and permissions, instead of leaving you with unexplained errors about temporary files. It keeps running either way, but nothing will survive a restart until it's fixed.
- **Your local channels stay your local channels.** ABC, CBS, NBC and FOX are pinned to your market's station. If that station is temporarily unavailable, the channel now shows as offline until it comes back, instead of quietly switching to another city's station. The old behaviour looked like it was working while carrying the wrong local news, sports and adverts, with nothing to tell you. It picks your own station back up automatically as soon as it returns.

## Update

Already running Rebel IPTV? Update to this version — your data (the `iptv-data` volume) is kept. From the dashboard, click **Update now** on the Dashboard or in **Settings → Server** (on the `:latest` image with the Docker socket mounted). Or from the command line:

```bash
docker pull rebeliptv/iptv:1.4.5
docker compose up -d
```

Setting up a **new** instance? The step-by-step guide at **https://www.rebeliptv.com** builds a Docker configuration for your system — ports, timezone, in-app updates, and more — so you copy a setup that fits your box instead of a generic one.

Image: `rebeliptv/iptv:1.4.5` (also published as `rebeliptv/iptv:latest`).

## Endpoints

| URL | Description |
|-----|-------------|
| `http://<server>:8080/playlist?key=YOUR_KEY` | M3U playlist |
| `http://<server>:8080/epg?key=YOUR_KEY` | EPG guide (XML) |
| `http://<server>:8080/epg.gz?key=YOUR_KEY` | EPG guide (gzip) |
| `http://<server>:8080` | Web dashboard |

> **Note:** The `?key=` parameter is only required if an API key has been generated in the web dashboard under **Settings**.
