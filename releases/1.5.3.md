## What's New

Pack a day's games onto fewer league channels, run your server on older Synology NAS models again, and refresh even very large playlists of your own.

#### Your server

- **Your server starts again on older Synology NAS models.** On a Synology whose system still runs Linux 3.10, 1.5.2 couldn't open its database and kept restarting. It starts there now.
- **A large playlist of your own no longer restarts your server.** A custom source with a very large playlist made your server's database run out of memory when it refreshed: a refresh from the dashboard failed, and the hourly one restarted your server, stopping whatever was playing. It refreshes now, even a playlist of 600,000 entries in a few seconds.

#### Sports

- **League channels can pack a day's games onto fewer channels.** Turn on Settings → Sports → Pack games onto fewer channels, and a later game goes on a league channel an earlier game has finished with, instead of a channel of its own. Two games share a channel only when the first one's postgame is over before the second one's pregame starts, so overtime never runs into the next game. Games already on a channel stay where they are, and no rescan is needed.
- **Games listed under a short team name get that stream too.** When a place your server finds games listed one under a short team name, such as "North Carolina" or "Appalachian St.", your server could miss it or read it as the other team, and the game lost that stream. Your server now reads both full names from the listing's address.

## Update

Already running Rebel IPTV? Update to this version — your data (the `iptv-data` volume) is kept. From the dashboard, click **Update now** on the Dashboard or in **Settings → System** (on the `:latest` image with the Docker socket mounted). Or from the command line:

```bash
docker pull rebeliptv/iptv:latest
docker compose up -d
```

On an image pinned to a version, change its tag in your compose file to `:1.5.3` and run `docker compose up -d`.

Setting up a **new** instance? The step-by-step guide at **https://www.rebeliptv.com** builds a Docker configuration for your system — ports, timezone, in-app updates, and more — so you copy a setup that fits your box instead of a generic one.

Image: `rebeliptv/iptv:1.5.3` (also published as `rebeliptv/iptv:latest`).

## Endpoints

| URL | Description |
|-----|-------------|
| `http://<server>:8080/playlist?key=YOUR_KEY` | M3U playlist |
| `http://<server>:8080/epg?key=YOUR_KEY` | EPG guide (XML) |
| `http://<server>:8080/epg.gz?key=YOUR_KEY` | EPG guide (gzip) |
| `http://<server>:8080` | Web dashboard |

> **Note:** The `?key=` parameter is only required if an API key has been generated in the web dashboard under **Settings → Security**.
