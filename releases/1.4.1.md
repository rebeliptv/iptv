## What's New

- **The dashboard now speaks your language.** It is available in Arabic, Dutch, English, Finnish, French, German, Hindi, Indonesian, Italian, Japanese, Korean, Malay, Norwegian, Portuguese, Simplified Chinese, Spanish, Swedish, Traditional Chinese and Urdu, and picks yours from your browser the first time you open it — change it any time from the globe in the top bar. Your choice is saved with the server rather than the browser, so it follows you to your phone and your TV box. Dates, times and durations now follow the language you picked too, temperatures outside the US read in °C, and Arabic and Urdu lay the whole dashboard out right-to-left.
- **A custom source pointed at a single stream now says so, instead of filling your lineup with junk.** If you added a stream address (one that ends in `.m3u8`) and set the source type to "playlist", it appeared to work — but every few seconds of that stream was imported as its own "channel", leaving hundreds of nonsense entries and no error to explain them. It now tells you to switch that source to **auto** or **direct**, which import it as the single channel it is.
- **Channels that stuttered every few seconds play smoothly again.** On some setups your server passed the picture straight through to your player the moment it arrived, keeping nothing in hand — so any brief hesitation upstream became a visible freeze. It now holds a few seconds in reserve, the way it already did everywhere else.
- **Live sport stops disappearing from your lineup after a momentary network hiccup.** Before your server can list a single game it has to look up the day's fixtures, and it was giving up on that lookup the first time a connection dropped mid-request. One unlucky moment could therefore leave you with no sport at all until the next refresh came round — even though everything involved was working. It now tries again before giving up.

## Update

Already running Rebel IPTV? Update to this version — your data (the `iptv-data` volume) is kept. From the dashboard, click **Update now** on the Dashboard or in **Settings → Server** (on the `:latest` image with the Docker socket mounted). Or from the command line:

```bash
docker pull rebeliptv/iptv:1.4.1
docker compose up -d
```

Setting up a **new** instance? The step-by-step guide at **https://www.rebeliptv.com** builds a Docker configuration for your system — ports, timezone, in-app updates, and more — so you copy a setup that fits your box instead of a generic one.

Image: `rebeliptv/iptv:1.4.1` (also published as `rebeliptv/iptv:latest`).

## Endpoints

| URL | Description |
|-----|-------------|
| `http://<server>:8080/playlist?key=YOUR_KEY` | M3U playlist |
| `http://<server>:8080/epg?key=YOUR_KEY` | EPG guide (XML) |
| `http://<server>:8080/epg.gz?key=YOUR_KEY` | EPG guide (gzip) |
| `http://<server>:8080` | Web dashboard |

> **Note:** The `?key=` parameter is only required if an API key has been generated in the web dashboard under **Settings**.
