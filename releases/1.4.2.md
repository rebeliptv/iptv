## What's New

- **You can now upload a guide file for your own M3U playlists.** Some sites build you a channel list and let you download its guide as an XMLTV file, but never publish a web address for it — so there was nothing to put in the EPG URL box. Edit a custom source and you can now hand it the `.xml` (or `.xml.gz`) directly. The file is checked as you upload it, so a wrong one is refused there and then rather than quietly leaving you with a blank guide, and because an uploaded guide only covers a fixed stretch of days, the source tells you when it has run out and needs a fresh one. Thanks to @zman982 for the request (#67).
- **Film posters are back in your guide.** Movies stopped showing their cover art a couple of months ago — the guide kept listing them correctly, but the artwork quietly stopped arriving and any poster already in place was cleared. Films now pick up their poster again, and as before it is the English-language, US release artwork, with anything we can't match left plain rather than given the wrong cover.
- **Live sports events have their full set of streams back.** Several of the sources behind sports events had quietly stopped working, so games were being listed with far fewer streams behind them than they should have had — and once the last working one failed, the channel simply went dark. Those sources are fixed, so an event now carries several alternatives again and a stream that drops falls back to another instead of stopping. If a source does break in future we'll now hear about it straight away rather than finding out from an empty schedule.

## Update

Already running Rebel IPTV? Update to this version — your data (the `iptv-data` volume) is kept. From the dashboard, click **Update now** on the Dashboard or in **Settings → Server** (on the `:latest` image with the Docker socket mounted). Or from the command line:

```bash
docker pull rebeliptv/iptv:1.4.2
docker compose up -d
```

Setting up a **new** instance? The step-by-step guide at **https://www.rebeliptv.com** builds a Docker configuration for your system — ports, timezone, in-app updates, and more — so you copy a setup that fits your box instead of a generic one.

Image: `rebeliptv/iptv:1.4.2` (also published as `rebeliptv/iptv:latest`).

## Endpoints

| URL | Description |
|-----|-------------|
| `http://<server>:8080/playlist?key=YOUR_KEY` | M3U playlist |
| `http://<server>:8080/epg?key=YOUR_KEY` | EPG guide (XML) |
| `http://<server>:8080/epg.gz?key=YOUR_KEY` | EPG guide (gzip) |
| `http://<server>:8080` | Web dashboard |

> **Note:** The `?key=` parameter is only required if an API key has been generated in the web dashboard under **Settings**.
